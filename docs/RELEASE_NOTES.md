# v1.0.0

First public release of the general-purpose Oligo Chemistry Toolkit.

- Formula / exact mass / average MW and OD260 calculations.
- 2D structures with MOL, SDF and CDXML export.
- Saved custom residues support bracket notation and 5′/3′ attachment sites.
- ChemDraw terminal marker recognition supports labelled terminal carbon/dummy placeholders.
- Public packaging excludes saved libraries, manufacturing/experiment schemas,
  environments, caches and historical development reports.

Windows x64 with Python 3.13 x64 is required; dependencies are installed separately.
See README for current chemistry and export limitations.
