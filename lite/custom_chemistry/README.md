# Custom Chemistry

此目录保存发布资源，不是浏览器用户库。

- attachment-demo.mol：attachment marker 示例。
- custom-MOE-5-3-example.mol：MOE 核苷 5/3 示例。
- custom-extinction.schema.json：可选 extinction metadata schema。

从根目录 Start.html → Advanced / Custom Chemistry 上传 MOL/SDF、确认 attachment、保存并使用 [ID]。数据仍由原 app.js 保存到 localStorage（oligo-lite-custom-v2）；备份/恢复使用页面的 library JSON 功能。
