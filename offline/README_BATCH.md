# Batch Post-functionalization

1. 完整解压 `Oligo-Toolkit-v2.4.2.zip` 到短路径，例如 `C:\Oligo`。用 Edge 或 Chrome 打开根目录的 `Start.html`。
2. 进入 **批量后修饰**。内置和当前用户库的试剂会自动载入。可一次选择本次用到的全部 MOL/SDF，并查看每条记录的解析结果。
3. 点 **生成 Excel 模板**。默认提供五个步骤列，可在生成前调整列数。每行填写一个产物的 ID、Sequence 和从左到右的步骤。每个步骤使用同一套下拉菜单，可选择试剂或二硫键还原。未使用的步骤请在行尾留空。
4. 保存工作簿，回到 Toolkit 导入。先点 **验证 / 预览**，再计算。需要导出结构时，选择所需格式并点 **计算 + 结构**。
5. 如果结果显示 **NEEDS REVIEW**，展开该行的候选列表，核对反应与位点，再点击所要的候选。Toolkit 会按当前选择重新执行批次，直到该路线完成或再次需要选择。

请先准备试剂，再为本次批次生成模板。中英文模板都可以在任一界面语言下导入。

临时结构保存在当前页面的内存中。重新选择文件会替换当前临时集合。刷新页面后请重新上传相同文件。多记录 SDF 的下拉项带有 `#记录号`。

换浏览器或解压到新目录时，原来的用户库可能需要迁移。可在原版本的 **自定义化学** 导出用户库 JSON，再在新版导入或合并。Batch 和 Builder 共用当前页面的用户库。

旧版两表式步骤工作簿需要迁移至新模板。仅含 ID 和 Sequence 的旧工作簿可通过列映射运行。

结果分别显示后修饰、结构导出和 OD 状态。结构和质量来自 Builder 的最终分子。部分产物的示意图和 OD 参数超出 Builder 当前的支持范围，可在结构详情和 OD 详情中查看原因。
