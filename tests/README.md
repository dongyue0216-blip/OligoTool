# Infinity I1 developer checks

The application launches through Start.html with no server. These optional regression checks use Node 24.

Run each active .cjs file in this directory. load-registry.js supplies the local registry. Each script raises an error or exits nonzero on failure. builtin-chain-audit writes its default evidence inside tests.

The Infinity baseline parity fixture was captured from the immutable CL2 archive. The data registry itself is unchanged.

UI and performance evidence is under evidence. Browser benchmark and acceptance function sources are included there. The experimental workspace also retains the complete browser runners, fixtures and initial failure logs.

The historical CL1 Team-specific harness was superseded by the CL2 UI and library-save suites.
